# DemoQA-cypress
Assignment

## Objective
Automate representative user interactions on DemoQA using Cypress and JavaScript.

## Scope
- Practice Form
- ModalDialogs
- SelectMenu

## Prerequisites
- Node.js and npm
- Chrome or another supported browser

## Installation
```bash
npm install
```

## Execution
Headless:
```bash
npm run test:e2e
```

Interactive/headed:
```bash
npm run test:headed
```

## Project Structure
- `cypress/e2e` - test specifications
- `cypress/pages` - Page Object Model classes and selectors
- `cypress/fixtures` - test data
- `cypress/support` - Cypress support/custom commands
- `cypress/utils` - reusable utilities

## Results
Execution results and screenshots should be added after the suite has been run.

Complete the TODO sections and validate all selectors/assertions against the current DemoQA application before submission.
